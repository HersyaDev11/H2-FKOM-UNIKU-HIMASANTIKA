# 🖥️ Landing Page Program Studi Teknik Informatika

## 📋 Deskripsi

Proyek ini merupakan sebuah **landing page** yang dirancang sebagai karya untuk mengikuti lomba web design dengan tema **"Program Studi Teknik Informatika"**. Website ini menampilkan informasi seputar Program Studi Teknik Informatika, mulai dari profil, visi & misi, kurikulum, dosen, fasilitas, hingga informasi pendaftaran mahasiswa baru, yang dikemas dalam tampilan modern, menarik, dan responsif di berbagai perangkat.

## 🎯 Tujuan

- Memperkenalkan Program Studi Teknik Informatika kepada calon mahasiswa
- Menyampaikan informasi akademik secara ringkas, jelas, dan menarik
- Menjadi media promosi digital yang mudah diakses di desktop maupun mobile

## ✨ Fitur

- **Hero Section** — tampilan awal berisi tagline dan *call-to-action*
- **Tentang Prodi** — profil singkat Program Studi Teknik Informatika
- **Visi & Misi**
- **Kurikulum** — gambaran mata kuliah/peminatan yang ditawarkan
- **Dosen** — profil singkat pengajar
- **Fasilitas** — laboratorium, ruang kelas, dan sarana penunjang lainnya
- **Prestasi/Portofolio Mahasiswa** *(opsional)*
- **Kontak & Media Sosial**
- **Formulir Pendaftaran/Kontak** *(opsional)*

## 🛠️ Teknologi yang Digunakan

- [Next.js](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- CSS *(Tailwind CSS / CSS Modules — sesuaikan dengan yang kamu pakai)*

## 🚀 Cara Menjalankan Project

1. Clone repository ini
   ```bash
   git clone [link-repository-kamu]
   ```
2. Masuk ke folder project
   ```bash
   cd nama-folder
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Jalankan development server
   ```bash
   npm run dev
   ```
5. Buka [http://localhost:3000](http://localhost:3000) di browser
